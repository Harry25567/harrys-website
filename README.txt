# Flappy Burst — GDevelop project

This is a Flappy Bird-style game made for GDevelop.

## Controls
- Space / click / touch: flap
- E: activate the Energy Burst
- The Energy Burst is a non-weapon power-up that clears the nearest pillar pair.
- Every 5 points recharges the Burst.

Open `game.json` in GDevelop 5 and preview the `Game` scene.
